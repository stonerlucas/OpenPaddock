## Data Sources

| Feature | Source |
|---|---|
| Live timing & telemetry | F1 SignalR |
| Historical stats & schedule | Ergast API |
| Detailed telemetry | FastF1 + OpenF1 |
| News | RSS Feeds |
| Community | Reddit API |
| Weather | Open-Meteo |
